# Home Wiki

Домашняя техническая wiki с короткими практическими заметками, SQL-шпаргалками и журналом задач по развитию репозитория.

## Структура

- `Linux/` - заметки по Linux и базовым системным инструментам.
- `Postgres/` - SQL и материалы по PostgreSQL.
- `Docker/` - базовые команды Docker, архитектура, volumes и registry.
- `GlusterFS/` - материалы по распределенному файловому хранилищу GlusterFS.
- `Vault/` - интеграция HashiCorp Vault с Kubernetes и External Secrets Operator.
- `Python/`, `Airflow/`, `Kubernetes/`, `Kafka/`, `Redis/`, `Ansible/`, `Terraform/`, `Git/`, `Elasticsearch/` - тематические разделы wiki.
- `TASK.md` - краткий реестр задач.
- `TASK_XXX.md` - подробные описания активных и запланированных задач.
- `Tasks/` - архив подробных описаний завершенных задач.
- `LOG.md` - журнал прогресса и контекста между сессиями.

## Как вести задачи

1. Добавить краткую запись в `TASK.md`.
2. Создать подробный файл `TASK_XXX.md` по шаблону из `TASK_TEMPLATE.md`.
3. Фиксировать ход работы в `LOG.md`, добавляя новые записи сверху.
4. После завершения задачи можно перенести ее подробный файл в `Tasks/` и обновить ссылку в `TASK.md`.

## Принципы наполнения

- Одна тема - один отдельный файл.
- Предпочтение коротким практическим заметкам с примерами.
- Для внутренних ссылок использовать относительные пути, чтобы wiki была переносимой между машинами.
