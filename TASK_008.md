## Кратко

Нужно подготовить отдельную инструкцию по Docker volumes: зачем они нужны, как создавать, подключать, смотреть, удалять и использовать для хранения данных контейнеров.

## Контекст

В разделе `Docker` уже есть базовая заметка по основным командам. Volumes заслуживают отдельного материала, потому что они отвечают за постоянное хранение данных, переносимость контейнеров и отделение данных приложения от жизненного цикла контейнера.

## Цель

Создать отдельный материал в каталоге `Docker` с понятной инструкцией по работе с Docker volumes и практическими примерами команд.

## Объем

- Объяснить, что такое Docker volume и зачем он нужен.
- Показать отличие volume от bind mount.
- Описать создание, просмотр, инспектирование и удаление volumes.
- Показать подключение volume при запуске контейнера через `-v`.
- Показать подключение volume через `--mount`.
- Добавить примеры сохранения данных на примере контейнера с PostgreSQL или Nginx.
- Показать копирование данных между volume и локальной файловой системой через временный контейнер.
- Добавить команды очистки неиспользуемых volumes.
- Указать важные замечания по удалению контейнеров и сохранности данных в volume.

- Сетевые и распределенные хранилища.
