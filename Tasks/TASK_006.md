## Кратко

Нужно подготовить материал по базовым командам для создания, просмотра, распаковки и сжатия архивов в Linux.

## Контекст

В домашней wiki уже есть материалы по базовым Linux-командам. Работа с архивами часто нужна при администрировании, переносе файлов, подготовке бэкапов и анализе скачанных пакетов, поэтому для этой темы нужен отдельный справочный материал.

## Цель

Подготовить понятную инструкцию по работе с архивами в Linux с практическими примерами команд для `tar`, `gzip`, `bzip2`, `xz`, `zip` и `unzip`.

## Объем

- Описать создание архивов с помощью `tar`.
- Показать распаковку архивов `.tar`, `.tar.gz`, `.tgz`, `.tar.bz2`, `.tar.xz`.
- Добавить команды просмотра содержимого архива без распаковки.
- Показать сжатие и распаковку отдельных файлов через `gzip`, `bzip2` и `xz`.
- Добавить примеры работы с `.zip` архивами через `zip` и `unzip`.
- Показать практические сценарии: архивирование каталога, распаковка в отдельную директорию, исключение файлов из архива.

## Вне объема

- Глубокий разбор всех опций архиваторов.
- Настройка резервного копирования как отдельного процесса.
- Работа с специализированными форматами вроде `7z`, `rar`, `cpio` и `zstd`.
- Шифрование архивов и управление ключами.
