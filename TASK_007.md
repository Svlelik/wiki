## Объем

- Создать отдельную папку `Docker` в корне wiki.
- Создать базовый материал в каталоге `Docker`.
- Описать проверку установленного Docker и версии клиента/сервера.
- Показать команды для работы с контейнерами: запуск, остановка, перезапуск, удаление, просмотр списка.
- Показать команды для работы с образами: загрузка, сборка, просмотр, удаление.
- Добавить команды для просмотра логов и входа внутрь контейнера.
- Добавить базовые команды для портов, переменных окружения и монтирования каталогов.
- Добавить краткий блок по сетям и томам Docker.
- Добавить команды очистки неиспользуемых контейнеров, образов, сетей и томов.
